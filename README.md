# السيرة الذاتية التفاعلية (Interactive Executive CV) 🚀

موقع سيرة ذاتية تفاعلي، عصري، فائق السرعة، ومبني بأحدث معايير الويب (HTML5, Vanilla CSS3, Vanilla JavaScript ES6+) بدون أي أطر عمل خارجية ثقيلة، ومخصص لمدراء تقنية المعلومات، إدارة المشاريع، والخدمات الحكومية.

🌐 **الرابط المباشر للموقع:** [cv.mohammed.alotaibi.site](https://cv.mohammed.alotaibi.site)

---

## ✨ المميزات الرئيسية للمشروع

- 🌐 **دعم كامل للغتين (Arabic & English):** تبديل سلس وفوري للنصوص واتجاه الصفحة (`RTL` و `LTR`) مع الحفاظ على التنسيق والخطوط المخصصة لكل لغة (Cairo للعربية و Inter للإنجليزية).
- 🌓 **وضع ليلي ونهاري ذكي (Dark & Light Mode):** دعم التبديل اليدوي مع التعرف التلقائي على تفضيلات نظام المستخدم وتخزين الخيار في `localStorage`.
- 🖨️ **تصدير وطباعة PDF متجهية متوافقة مع أنظمة التوظيف (ATS-Compliant Vector PDF):** تنسيق طباعة `@media print` مصمم بمقاس A4 يضمن حفظ مستند نصي عالي الدقة وقابل للبحث والفرز الآلي.
- 📇 **بطاقة اتصال رقمية تفاعلية (vCard):** تحميل مباشر لملف جهة الاتصال `.vcf` لحفظ البيانات فوراً في الهاتف.
- 📱 **نافذة رمز الاستجابة السريعة (Interactive QR Code Modal):** عرض رمز QR عالي الدقة لمسحه بكاميرا الجوال مع إمكانية تحميل صورة الرمز كـ PNG.
- 🚀 **مشاركة السيرة الذاتية (Web Share API):** مشاركة الرابط مباشرة عبر التطبيقات في الهواتف.
- 🔍 **بحث وتصفية لحظية (Instant Live Search):** إمكانية البحث الفوري في المهارات، المشاريع، الشركات، الشهادات، والخبرات.
- 🏷️ **فلاتر المهارات السريعة (Quick Skill Filters):** أزرار تصفية المهارات حسب التصنيف (الكل، أنظمة التشغيل، الشبكات، السحابة، والقيادة).
- 📶 **العمل بدون اتصال بالإنترنت (Offline PWA & Service Worker):** ملف `sw.js` يضمن فتح السيرة والتنقل فيها بسرعة فائقة حتى في حال انقطاع الإنترنت.
- ⚙️ **أتمتة النشر عبر GitHub Actions (CI/CD):** سير عمل تلقائي للنشر على GitHub Pages عند كل `git push`.
- 🔍 **تحسين محركات البحث الكامل (SEO & Social Sharing):**
  - ملف `sitemap.xml` و `robots.txt`.
  - وسوم Open Graph و Twitter Cards لبطاقات المعاينة الاجتماعية.
  - بيانات مهيكلة Schema.org JSON-LD لنوع `Person`.

## 🛠️ هيكل ملفات المشروع

```
cv/
├── .github/
│   └── workflows/
│       └── deploy.yml      # سير عمل النشر التلقائي عبر GitHub Actions
├── index.html              # الهيكل الدلالي، الميتا داتا، والـ QR Modal
├── styles.css              # نظام التصميم، المتغيرات، التجاوب، ونمط الطباعة
├── script.js               # المنطق البرمجي، vCard، QR Canvas، والبحث السريع
├── data.js                 # قاعدة بيانات السيرة الذاتية (عربي / إنجليزي)
├── sw.js                   # ملف Service Worker للعمل دون إنترنت (PWA)
├── robots.txt              # تنظيم وتوجيه زواحف محركات البحث
├── sitemap.xml             # خريطة الموقع لمحركات البحث
├── CNAME                   # ربط النطاق المخصص (Custom Domain)
├── images/                 # الصورة الشخصية، الأيقونات، وملف الـ Webmanifest
└── README.md               # دليل ومواصفات المشروع
```

## 📝 كيفية تحديث البيانات

لتعديل أو إضافة أي بيانات (الخبرات، المهارات، المشاريع، المؤهلات، أو وسائل التواصل):
1. افتح ملف `data.js`.
2. عدل النصوص والبيانات في قسم `ar` للغة العربية وقسم `en` للغة الإنجليزية.
3. احفظ الملف، وسيقوم GitHub Actions بنشر التحديث تلقائياً!
