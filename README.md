# السيرة الذاتية التفاعلية (Interactive Executive CV) 🚀

موقع سيرة ذاتية تفاعلي، عصري، وسريع الاستجابة مبني بأحدث معايير الويب (HTML5, Vanilla CSS3, Vanilla JavaScript ES6+) بدون أي أطر عمل خارجية ثقيلة، ومخصص لمدراء تقنية المعلومات وإدارة المشاريع.

🌐 **الرابط المباشر:** [cv.mohammed.alotaibi.site](https://cv.mohammed.alotaibi.site)

---

## ✨ المميزات الرئيسية

- 🌐 **دعم كامل للغتين (Arabic & English):** تبديل سلس وفوري للنصوص واتجاه الصفحة (`RTL` و `LTR`) مع الحفاظ على التنسيق والخطوط المخصصة لكل لغة (Cairo للعربية و Inter للإنجليزية).
- 🌓 **وضع ليلي ونهاري ذكي (Dark & Light Mode):** دعم التبديل اليدوي مع التعرف التلقائي على تفضيلات نظام المستخدم، وتخزين الخيار في `localStorage`.
- 🖨️ **تصدير وطباعة PDF متجهية متوافقة مع أنظمة التوظيف (ATS-Compliant Vector PDF):** تنسيق طباعة `@media print` مصمم بمقاس A4 يضمن حفظ مستند نصي عالي الدقة وقابل للبحث والفرز الآلي.
- 🔍 **بحث وتصفية لحظية (Instant Live Search):** إمكانية البحث الفوري في المهارات، الشركات، الشهادات، والخبرات.
- 📱 **تصميم متجاوب بالكامل (Fully Responsive):** تجربة مثالية على جميع مقاسات الشاشات (الهواتف، الأجهزة اللوحية، والشاشات العريضة).
- ⚡ **أداء فائق وSEO متقدم:**
  - أوقات تحميل شبه فورية بدون حزم زائدة.
  - دعم Open Graph و Twitter Cards لإنشاء بطاقات معاينة مميزة عند مشاركة الرابط عبر وسائل التواصل وواتساب.
  - بيانات مهيكلة Schema.org JSON-LD لنوع `Person`.

## 🛠️ هيكل المشروع

```
cv/
├── index.html        # الهيكل الدلالي والمعايير القياسية للـ SEO والـ Head
├── styles.css        # نظام التصميم والمتغيرات (Design System Tokens, Responsive & Print)
├── script.js         # المنطق البرمجي، إدارة الحالة، البحث، وتوليد المحتوى
├── data.js           # قاعدة بيانات السيرة الذاتية باللغتين العربية والإنجليزية
├── CNAME             # ربط النطاق المخصص (GitHub Pages Custom Domain)
├── images/           # الصورة الشخصية، الأيقونات، وملف الـ Webmanifest
└── README.md         # دليل المشروع
```

## 📝 كيفية تخصيص البيانات

لتعديل أو إضافة أي بيانات (الخبرات، المهارات، المؤهلات، أو وسائل التواصل):
1. افتح ملف `data.js`.
2. عدل النصوص والبيانات في قسم `ar` للغة العربية وقسم `en` للغة الإنجليزية.
3. احفظ الملف، وسيتم تحديث الموقع تلقائياً.
